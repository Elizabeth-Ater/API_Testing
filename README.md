Exploring and Testing APIs with Postman
Overview

This repository contains the Postman collection, environment, and documentation for the "Exploring and Testing APIs with Postman" assignment. The GitHub REST API v3 was used to demonstrate authentication, CRUD operations, environment variables, and automated testing.

API Used: GitHub REST API v3
Base URL: https://api.github.com
Authentication Method: Bearer Token (GitHub Personal Access Token)
Resource Used for CRUD: Gistsgit
